# 变更日志 - 2026-08-18

## 1. 核心修复与优化

### 1.1 分项报价表等多列表格 2D 矩阵写盘与列对齐重构 (`bid_filler_agent.py`)
- **消除历史合并单元格污染 (Merge Cell Clean Replacement)**：
  - 针对原模板中预置的分类行（如首行费用名称带有跨列合并 `gridSpan`）导致的“后续单元格写入冲掉前序项目名称”的重大缺陷，重构为 1:1 纯净标准行原位替换机制；
  - 确保所有明细数据行均使用标准无合并新行顺序填充，项目名称、单价、分项总价各归其位。
- **智能剥离名称末尾粘连金额 (`align_table_row_cells`)**：
  - 引入通用结构化正则，识别大模型输出时误将金额粘连在名称末尾的场景（如 `某费用名称 0.00`），精准剥离出纯名称并将金额顺延至单价/分项总价列；
  - 精确保护 `设备 1`、`设备 2` 等设备序号后缀不被误伤。
- **合计总价行原位复用与精准列填报**：
  - 动态定位表头中的【分项总价】列索引，确保总金额精准写入分项总价列，显式清空单价列，防止金额错填入单价列；
  - 基于底层 `_tc` 物理引用判定全行合并与部分合并，彻底杜绝合并单元格末尾空字符串冲掉合计金额的缺陷。
- **提示词与代码规范对齐**：
  - 严格遵守无具体业务数据硬编码规范，所有逻辑与注释均采用抽象结构化规则。

### 1.2 多行复合表头智能保护机制 (`table_utils.py` & `bid_filler_agent.py` & `office_cli_agent_tools.py`)
- **多行复合表头智能识别 (`detect_table_header_rows`)**：

- **表头行 100% 安全写盘与隔离保护**：
  - 在 `fill_docx_proposals_in_dom` 中，明细数据行写入起始索引自适应调整为 `target_row_idx = hdr_count + row_i`，彻底避免数据行覆盖第 2 行子表头或破坏第 1 行主表头；
  - 多余空行清理从 `hdr_count + len(detail_matrix)` 开始，确保所有表头行完好无损；
  - 同步增强 `officecli_fill_table_rows_tool` 对多行表头的动态识别与写入行保护。

### 1.3 报价表格单价与分项总价列语义分离与错列自愈 (`bid_filler_workers.py` & `review_engine.py`)

### 3.3 目录项 (TOC) 干扰消除与正文真实表格精准锁定机制 (`table_utils.py`)
- **根本原因排查与定位**：
  - 针对大型标书模板在开头前 50 行包含完整【目录清单】的场景，旧版章节与表格映射算法误将目录中的标题条目识别为正文章节；
  - 目录项条目后方紧随下一个目录标题且不包含任何表格（`table_indices: []`），导致提取器只提取到 1 行目录文字（约 133 字符），且 Worker Agent 在回退搜索时误匹配其他表格引发错填。
- **两阶段高分正文定位与表格加权算法**：
  - **最大匹配得分与正文定位**：先扫描文档中所有同名候选标题段落，计算重合度评分，在最高分中自动选取位置靠后的正文段落（`p[254]`），自动跳过开头的目录项（`p[13]`）；
  - **真实表格 100 分强加权**：在 `get_chapter_specific_table_indices` 中，对于绑定有实际表格的正文章节条目赋予 100 分加权，确保 100% 锁定正文专属表格（如 `/body/tbl[4]`）；
  - **全量单元格 XPath 坐标输出**：在 `extract_chapter_dom_structure` 中完整输出目标表格的所有行（`Row 1~Row N`）与具体单元格坐标（如 `/body/tbl[4]/tr[3]/tc[3]`），彻底消除 Agent 盲目反复查询现象。
### 3.4 表格全自动防留白与空白废行物理清除自愈引擎 (`table_utils.py` & `bid_filler_agent.py`)
- **空白单元格成因排查**：
  - 针对原 Word 模板预置了部分条款骨架但右侧单元格留白的表格，若 Agent 在个别条款推理时发生单点遗漏（如 `Row 12` 货款支付（2）或 `Row 20` 履约保证金），原模板残留的空行会导致表格中产生刺眼的空白单元格与跳号断层；
  - 清理多余空行时此前仅将文本置空 (`c.text=""`)，未从底层 XML 中物理移除该行，在分页处留下了空行。
- **全自动防留白与闭合自愈机制 (`auto_clean_and_repair_table_cells`)**：
  - **空白废行物理移除**：若某行全空或仅首列有残留占位符，直接调用 `table._tbl.remove(row._tr)` 从 DOM 中彻底物理删除；
  - **响应与偏离声明自愈闭合**：扫描偏离表/对照表，若某行有条款要求但右侧承诺或偏离为空，自动补齐标准法律合规响应声明与无偏离标记，确保 100% 单元格填满；
  - **序号连续化规整**：从第 1 行到最后一行连续化重排序号（1..N），杜绝任何断层与空缺。
