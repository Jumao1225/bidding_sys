# 项目改动记录 (Changelog) - 2026-07-30

## 标书打分 Agent (`BidScorerAgent`) 三层架构重构与交互式人工标注支持

根据标书打分系统核心规范，完成了文档解析层、认知与检索层以及智能推理层的全面重构，并扩展了交互式人工切片与章节标注工作流 API。

---

### 1. 模块一：文档解析层与交互式人工标注 (Parsing & Human Annotation)
- **多模态视觉理解预留**:
  - 新增 [multimodal_vision_service.py](file:///d:/Myproject/bidding_sys/backend/app/services/multimodal_vision_service.py)，定义 `MultimodalVisionService` 类。
  - 预留平面布置图、节点图、设备安装图等视觉图纸信息的文本语义转换接口 `extract_image_insights()`。
- **汉字序号大章与 Markdown 目录自动解析切片 ([extractor_service.py](file:///d:/Myproject/bidding_sys/backend/app/services/extractor_service.py))**:
  - 全量放开 `一、`、`二、`、`三、` 汉字序号以及 Markdown `#` / `##` 层级标题切片，精确绑定 `section_title` 与 `parent_chapter`。
- **交互式人工切片与章节标注 API (Human-in-the-Loop Annotation)**:
  - 在 [bid_scorer_schema.py](file:///d:/Myproject/bidding_sys/backend/app/schemas/bid_scorer_schema.py) 中新增 `DocChunkDetailResponse` 与 `ChunkBatchUpdateRequest` 模型。
  - 在 [bid_scorer_service.py](file:///d:/Myproject/bidding_sys/backend/app/services/bid_scorer_service.py) 中新增 `get_document_chunks_for_annotation()` 与 `save_human_annotated_chunks()`，实现人工修改章节名/切片文本后的向量重计算与 `human_annotated` 状态更新。
  - 在 [bid_scorer.py](file:///d:/Myproject/bidding_sys/backend/app/api/endpoints/bid_scorer.py) 中提供 2 个新 API 端点：
    - `GET /api/v1/bid-scorer/chunks/{document_id}`：拉取全量切片供前端渲染与标注；
    - `PUT /api/v1/bid-scorer/chunks/{document_id}/batch-update`：批量提交保存人工标注切片。
- **前端可视化切片与章节标注工作台 (`ChunkAnnotationWorkbench.tsx`)**:
  - 新增 **【📄 真实原文件 (PDF / Word)】与【📝 提取 Markdown】** 两种双栏对照视图；
  - 集成 `SmartDocViewer`，并修复后端 `/api/v1/analysis/download/{task_id}` 原文件免认证流式下载端点；
  - **组件记忆化 (`useMemo`)**：记忆 `viewerDocuments` 引用，彻底解决编辑切片或手打章节时 PDF 视图重复刷新与滚动条弹回第 1 页的问题；
  - **【🖼️ 矩形框选图片/盖章 (Box Select)】工具**：允许用户在 PDF / Word 原图上拖动鼠标画矩形框，秒级截取任何图片、盖章、表格或架构图，一键封装为图像切片并绑定物理章节。

### 2. 模块二：认知与检索层 (Multi-Level Indexing & Context Budgeting)
- **多级索引 RAG 检索**:
  - 修改 [bid_scorer_tools.py](file:///d:/Myproject/bidding_sys/backend/app/agents/tools/bid_scorer_tools.py) 的 `retrieve_bid_content_for_category()`。
  - **动态关键词提取 (`_extract_dynamic_keywords`)**：从评分项的 `title`、`sub_category` 与 `scoring_criteria` 中动态抽取实体词。
  - **双层索引融合**：融合“一级：章节结构索引 (Chapter Index)”与“二级：语义切片索引 (Semantic Index)”。
  - **上下文预算管理 (Context Budgeting)**：增加去重与最大字符数限制（默认 14,000 字）。
- **提示词规范化 (CO-STAR 框架)**：
  - 升级 `_build_scoring_prompt()`，明确 Context, Objective, Style, Tone, Audience 与 Default to Null。
- **中位数贴合度选优共识 (Median-Proximity Selection)**：
  - 重构 `compute_consensus()`，选择得分与 `median_score` 绝对距离最小的轮次作为 `best_round`。

---

### 3. 模块三：智能推理层 (Supervisor + N 专项 Agent)
- **Supervisor-Specialist 架构构建**:
  - 重构 [bid_scorer_agent.py](file:///d:/Myproject/bidding_sys/backend/app/agents/bid_scorer_agent.py)。
  - **`supervisor_load_node`**：负责评分维度树的加载与领域拆解分配（如技术参数专项 `tech_param_subagent`、方案评估专项 `plan_eval_subagent`、商务/资质专项 `commercial_subagent`）。
  - **`specialist_score_node`**：由 Supervisor 派发并行执行多级检索与多轮共识打分。
  - **`supervisor_aggregate_node`**：汇总所有专项子 Agent 的计算结果，执行数学校验与 L5 分值强制截断。
  - **`supervisor_report_node`**：调用 LLM 生成总体评价报告，按潜在提分幅度 (`gap`) 降序输出 Top 10 改进建议。
